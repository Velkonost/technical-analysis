class IchimokuA(high: DataColumn<BigDecimal>, low: DataColumn<BigDecimal>, window1: Int = 9, window2: Int = 26, window3: Int = 52, visual: Boolean = false, fillna: Boolean = false) : Indicator

Ichimoku Leading Span A (Senkou Span A) indicator implementation. The Leading Span A is a component of the Ichimoku Cloud system, representing the first cloud boundary. It is calculated as the average of the Conversion Line and Base Line, shifted forward by the Base Line period. Together with Leading Span B, it forms the Ichimoku Cloud (Kumo).

class IchimokuB(high: DataColumn<BigDecimal>, low: DataColumn<BigDecimal>, window1: Int = 9, window2: Int = 26, window3: Int = 52, visual: Boolean = false, fillna: Boolean = false) : Indicator

Ichimoku Leading Span B (Senkou Span B) indicator implementation. The Leading Span B is a component of the Ichimoku Cloud system, representing the second cloud boundary. It is calculated as the midpoint between the highest high and lowest low over a longer period (window3), shifted forward by the Base Line period. Together with Leading Span A, it forms the Ichimoku Cloud (Kumo).

Ichimoku Base Line (Kijun-sen) indicator implementation. The Base Line is a component of the Ichimoku Cloud system, representing the medium-term trend. It is calculated as the midpoint between the highest high and lowest low over a longer period than the Conversion Line, making it a more stable reference point.
